Record cache does not count the source raw record, so it never evicts large-value entries

0 条回复 · 1 位参与者

讨论聚焦 Kafka Streams 记录缓存因未计入源记录原始 key/value 而导致内存占用低估的问题。该缺陷会使大源记录、小存储值场景下缓存无法按 statestore.cache.max.bytes 正常淘汰，最终可能耗尽堆内存。

@Paul Scarrone: 自 KAFKA-16505 起，LRUCacheEntry 会复制保存源记录的原始 key/value，但 ProcessorRecordContext#residentMemorySizeEstimate() 未计入这部分大小，导致 ThreadCache 少计内存；建议在 LRUCacheEntry 的 sizeBytes 中加入 rawKey/rawValue 长度。

初步修复方向是调整 LRUCacheEntry 的大小计算以包含源记录原始 key/value，作者表示可提交包含测试用例的 PR。
