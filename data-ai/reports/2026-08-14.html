AWS 展示基于 OpenSearch 的 AI Agent blame graph

📌 AWS Big Data Blog

2026-08-14

AWS Big Data Blog 展示如何在 Amazon OpenSearch Service 与 Amazon Bedrock 之上构建 blame graph，用于追踪多个 AI agent 协作决策失败时的责任路径。文章指出标准日志难以判断哪个 agent 造成错误，blame graph 可度量 agent 间影响，并从失败决策反向回溯，为 AI 系统提供更细粒度的可观测性。

📊 数据平台影响：该方案将图关系、trace 和评估数据纳入 OpenSearch，扩展数据平台在 AI Ops 中的角色，推动平台支持 agent 日志、因果分析和责任追踪。

Autodesk 23 亿文档迁移至 Amazon OpenSearch Service

📌 AWS Big Data Blog

2026-08-14

AWS 介绍 Autodesk 如何将 23 亿份文档迁移到 Amazon OpenSearch Service。Autodesk 将原本单一索引的 Elasticsearch 7.1.1 域重构为四个多索引 OpenSearch 域，并使用 Migration Assistant 与智能路由层，将查询导向承载相关数据的 shard，以改善规模、性能和成本。

📊 数据平台影响：该案例为超大规模搜索与文档平台提供迁移范式，多索引拆分与智能路由有助于降低热点、提升查询效率，并增强数据平台架构弹性。
