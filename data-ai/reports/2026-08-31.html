Amazon Kinesis Data Streams 推出 Apache Iceberg streaming tables

📌 AWS Big Data Blog

2026-08-31

Amazon Kinesis Data Streams 推出 streaming tables，将流数据持续写入 Amazon S3 Tables，并以可查询的 Apache Iceberg 表形式提供。AWS 称该能力通过内联 compaction 降低最高 25% 交付成本和 30% 查询成本，减少用户自建流式入湖、表维护和查询优化流程。此举进一步整合实时摄取、开放表格式和对象存储表服务。

📊 数据平台影响：实时数据可直接沉淀为 Apache Iceberg 表，降低流式湖仓链路复杂度，增强 S3 Tables 与开放表格式生态绑定，对 Flink、Kafka 及第三方入湖管道形成竞争压力。

Amazon Redshift 支持 IAM Identity Center 与 enhanced VPC routing 集成

📌 AWS Big Data Blog

2026-08-31

Amazon Redshift 现支持在启用 enhanced VPC routing 的集群和 workgroup 上使用 AWS IAM Identity Center 认证。企业可通过两个 interface VPC endpoint 实现公司凭据单点登录，同时让认证流量保留在 AWS 私有网络内。该更新主要面向安全合规、统一身份和私有网络访问需求。

📊 数据平台影响：数据仓库身份认证与企业 SSO、私网访问进一步打通，有助于大型组织统一治理 Redshift 访问权限，降低网络暴露和身份管理复杂度。

AWS Glue 6.0 支持 Spark Real-Time Mode 构建实时事件管道

📌 AWS Big Data Blog

2026-08-31

AWS Glue 6.0 支持在单一平台上构建实时、近实时和批处理数据管道。文章以金融市场风险为例，展示使用 Spark Real-Time Mode 在亚秒级标记高风险交易，并结合 Apache Iceberg v3 Variant 存储异构定价向量。该能力显示托管 ETL 正加速走向流批一体和半结构化数据处理。

📊 数据平台影响：Glue 6.0 将流批管道统一到托管 Spark 环境，降低多引擎拼接成本，也推动 Iceberg Variant 等半结构化能力在数据平台落地。

Amazon OpenSearch Service 强化搜索质量度量与相关性优化

📌 AWS Big Data Blog

2026-08-31

AWS 发布博客介绍如何在 Amazon OpenSearch Service 中采集 User Behavior Insights（UBI）数据，并使用 Search Relevance Workbench（SRW）将用户行为信号转化为相关性判断，评估和改进搜索质量。该方案面向搜索团队难以量化“结果是否相关”的常见问题。

📊 数据平台影响：搜索质量评估从经验判断转向行为数据闭环，为 RAG、检索增强和电商搜索提供更可量化的相关性治理工具。
