AWS 将 Glue Data Quality 原生引入 Amazon EMR

📌 AWS Big Data Blog

2026-10-12

AWS 宣布 AWS Glue Data Quality 现已原生运行在 Amazon EMR 的 Apache Spark 运行时 emr-spark-8.1.0 中。用户可以在 EMR Spark 作业中直接复用 Glue 的 DQDL 规则，实现轻量级内联数据校验，或结合 Apache Iceberg 表构建更完整的数据质量门。该能力将数据质量检查嵌入湖仓与大数据计算工作负载，减少额外编排和独立质量服务。

📊 数据平台影响：数据质量从旁路治理转向计算引擎内建，有助于 EMR/Iceberg 湖仓在入湖、加工和发布环节统一质量策略，提升可信数据供给效率。

AWS 发布跨账号 Amazon Kinesis 流式管道构建指南

📌 AWS Big Data Blog

2026-10-12

AWS Big Data Blog 介绍如何使用 Kinesis Producer Library 和 Kinesis Client Library，在三个独立 AWS 账号之间构建企业级跨账号流式数据管道。方案结合资源型策略、跨账号 IAM 权限和共享客户托管 AWS KMS 密钥，覆盖生产者、消费者与加密密钥分离的企业安全模型，为多账号数据平台提供可复制的实时数据分发架构。

📊 数据平台影响：为多账号企业实时数据平台提供安全边界清晰的参考架构，降低跨组织、跨环境 Kinesis 数据共享与治理门槛。

StarTree 提出 Query Abundance：当机器开始提问

📌 StarTree Blog

2026-10-12

StarTree 博客文章提出“Query Abundance”概念，认为大数据时代的第一个反转是机器产生数据超过人类，而下一阶段将是机器发起的查询超过人类查询。随着 AI agent、自动化分析和嵌入式智能应用普及，数据平台不再只服务人类分析师的交互式提问，还要承接高频、并发、自动化的机器问题。文章指出这要求平台在查询模式、索引、语义层、成本和实时性上重新设计。

📊 数据平台影响：AI agent 将放大查询负载并改变工作负载形态，实时 OLAP、语义索引、查询缓存与成本控制将成为平台竞争力。
