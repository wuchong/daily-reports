Amazon MWAA 支持 Airflow 3.0 实现跨账户事件驱动编排

📌 AWS Big Data Blog

2026-08-06

AWS 宣布 Amazon MWAA 现已支持 Apache Airflow 3.0。新版本引入了 asset-based scheduling 和 Asset Watchers 功能，结合 Amazon SQS，使数据工程团队能够构建跨多个 AWS 账户的事件驱动型工作流，解决了以往不同 MWAA 环境间缺乏原生协调机制的问题。

📊 数据平台影响：此举解决了数据网格架构中跨域编排的难题。通过原生支持跨账户事件触发，AWS 降低了构建复杂数据管道的运维门槛，提升了多环境下的架构灵活性，巩固了其在云原生数据编排领域的领先地位。

AWS 发布企业级 Lakehouse 细粒度访问控制扩展方案

📌 AWS Big Data Blog

2026-08-06

针对企业 Lakehouse 规模化后权限管理成为瓶颈的问题，AWS 提出了结合 IAM Identity Center、Lake Formation 标签化访问控制以及 SageMaker Unified Studio 可信身份传播的综合解决方案。该方案旨在实现跨业务域和区域的大规模细粒度治理。

📊 数据平台影响：治理是数据平台从“可用”走向“好用”的关键瓶颈。该方案打通了数据湖与 AI 开发环境的权限壁垒，通过标签策略自动化管理，有效缓解了数千张表带来的权限管理压力，加速了 Data+AI 统一治理平台的落地。
