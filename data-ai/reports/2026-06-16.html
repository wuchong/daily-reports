📡 重要信号

AWS 发布 Redshift RA3 至 Graviton 实例迁移最佳实践

📌 AWS Big Data Blog

2026-06-16

AWS 官方发布详细指南，指导用户将 Amazon Redshift RA3 集群迁移至基于 Graviton 的 RG 实例。文章深入对比了 Elastic Resize、Classic Resize 和 Snapshot/Restore 三种迁移策略的优劣，并提供了关键的映射指导与最佳实践，旨在帮助用户利用 Graviton 处理器实现更优的性价比。

📊 数据平台影响：这是 AWS 数据仓库全面向自研芯片架构转型的关键信号。迁移至 Graviton 将显著降低用户的计算成本（TCO），同时提升 AWS 自研芯片在数据基础设施中的渗透率，对传统 x86 架构的数据仓库供应商构成更大的成本竞争压力。

SageMaker Unified Studio 集成 Kiro 与 Cursor 支持 AI 辅助开发

📌 AWS Big Data Blog

2026-06-16

AWS 宣布通过 AWS Toolkit for VS Code，支持将 Kiro、VS Code 或 Cursor 等 IDE 直接连接至 Amazon SageMaker Unified Studio。该功能打通了主流 AI 编程助手与 AWS 数据开发环境的连接，允许开发者在熟悉的编辑器中利用 AI 能力进行数据处理与模型开发。

📊 数据平台影响：顺应 AI 辅助编程趋势，打破了数据平台封闭的开发环境。通过支持 Cursor 等热门 AI IDE，AWS 降低了数据开发门槛，提升了开发者体验，有助于增强平台对新一代 AI 开发者的粘性。
