Amazon Redshift 推进 Apache Iceberg 写入与表演进能力

📌 AWS Big Data Blog

2026-09-28

AWS 发布 Amazon Redshift Apache Iceberg 写入支持系列第三篇，介绍通过 ALTER 语句演进 Iceberg 表结构和分区布局。用户可重命名、新增、删除和扩展列，并演进分区，而无需重写数据或重建管道。文章还展示如何创建 AWS Lake Formation resource links，进一步连接湖仓目录与权限体系。

📊 数据平台影响：Redshift 将 Iceberg 从读取扩展到写入和元数据演进，增强湖仓一体竞争力，降低企业从专有表格式迁移到开放表格式的成本，也会推动 Lake Formation 成为统一治理层。

ClickHouse 推出 chDB Durable Layer，面向 Agent Memory 的持久化分析层

📌 ClickHouse Blog

2026-09-28

ClickHouse 发布 chDB Durable Layer，用于保存 AI agent memory。该层在本地保持高速查询能力，同时让分析状态可在笔记本、CI 任务和短生命周期沙箱之间恢复。其目标是为 agent 提供可持久、可审计、可复用的上下文状态，而不是只依赖临时缓存或外部向量库。

📊 数据平台影响：chDB 将分析型数据库能力嵌入 Agent 运行时，推动数据库从查询引擎扩展为 Agent 状态基础设施。这可能为本地化、边缘化和 CI 内 AI 工作流提供更轻量化的记忆层。

Amazon SageMaker Unified Studio 支持 Tooling blueprint 的 IAM 权限边界

📌 AWS Big Data Blog

2026-09-28

AWS 介绍 Amazon SageMaker Unified Studio Tooling blueprint 新增自定义 IAM permissions boundaries 能力。用户可创建限制 AI agent 能力的权限边界，通过 AWS CLI 配置到 Tooling blueprint，并验证每个自动创建的 IAM role 是否符合最小权限要求。这有助于企业在自动化 AI 工具链中加强安全治理。

📊 数据平台影响：AI Agent 工具链正从可用性转向可治理性。将权限边界嵌入 SageMaker blueprint，有助于企业把数据访问、模型调用和工具执行纳入统一安全模型，降低自动化 Agent 越权风险。
