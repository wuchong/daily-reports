Automate Spark Scala migration to 4.x with AWS Spark Upgrade Agent

📌 AWS Big Data Blog

2026-07-28

AWS 发布 AWS Spark Upgrade Agent，旨在自动化 Amazon EMR 上 Apache Spark 3.x 到 4.0 的 Scala 迁移工作。该工具能够处理 API 弃用、行为变更和构建配置更新，并通过作业验证确保迁移稳定性，将原本耗时数月的手动工作缩减至数小时。

📊 数据平台影响：Spark 大版本升级通常面临极高的兼容性成本，AWS 此举通过自动化工具显著降低了用户留在 EMR 平台的技术门槛，有助于加速 Spark 4.0 在企业数据平台的普及，同时强化了 EMR 相对于自建 Spark 集群的运维优势。

Build a contract compliance search system with Amazon OpenSearch

📌 AWS Big Data Blog

2026-07-28

AWS 展示了如何使用 Amazon OpenSearch Service 构建合同合规搜索系统。该方案结合了语义搜索与语义高亮功能，通过 CloudFormation 部署，能够从合成合同文档中精准定位合规相关信息，展示了 OpenSearch 在非结构化文档智能处理方面的能力。

📊 数据平台影响：这标志着 OpenSearch 正从传统的日志分析工具向企业级智能搜索平台演进。通过集成语义搜索能力，OpenSearch 增强了其在法律、合规等垂直领域的竞争力，为数据平台处理非结构化数据提供了新的参考架构。
