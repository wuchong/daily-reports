AWS Glue 6.0 支持 Apache Iceberg v3 关键新特性

📌 AWS Big Data Blog

2026-08-27

AWS 发布博客称，AWS Glue 6.0 搭配 Apache Spark 4.1 支持 Apache Iceberg v3，包括原生 geospatial 类型、纳秒精度时间戳、VARIANT 类型和 DEFAULT 列值。文章以车联网车队遥测管道为例，展示如何在单张 Iceberg v3 表中同时处理位置数据、事件负载、半结构化数据和高精度时间序列。

📊 数据平台影响：AWS 将 Iceberg v3 复杂类型引入 Glue，将增强湖仓对 IoT、日志、半结构化与地理空间数据的统一建模能力，也可能进一步推动 Iceberg 成为 AWS 数据湖生态的核心表格式。

Picnic 在 Amazon MQ for RabbitMQ 上配置多 OAuth 提供方

📌 AWS Big Data Blog

2026-08-27

AWS 博客介绍 Picnic 将 Amazon MQ for RabbitMQ 作为数百个微服务的消息总线，并配置同一个 broker 信任多个 OAuth 2.0 身份提供方：运维人员使用 Keycloak，服务身份使用 AWS IAM。该方案在保持访问控制的同时消除静态凭据。

📊 数据平台影响：该实践为数据平台的消息层提供零信任身份模板，有助于数据管道、事件流和微服务通信从静态密钥管理转向联邦身份、短期凭据和细粒度授权。
