📡 重要信号

AWS OpenSearch Service 推出可写温存储，基础设施成本降低高达 48%

📌 AWS Big Data Blog

2026-07-08

AWS 宣布 Amazon OpenSearch Service 支持可写温存储。该功能消除了在热存储和温存储之间迁移数据的昂贵周期，允许用户直接更新历史数据。据官方数据，此举可将基础设施成本降低高达 48%，并将历史数据更新时间从数小时缩短至数秒。

📊 数据平台影响：此举解决了 OpenSearch 长期以来温数据“只读”且迁移复杂的痛点。对于数据平台工程师而言，这意味着存储分层策略更加灵活，企业可以更低成本地保留更多历史数据用于实时分析，提升了数据湖仓架构在日志分析场景的竞争力。

💻 产品与技术

Redpanda 提出 Agentic Data Plane：连接 AI Agent 与数据的新治理层

📌 Redpanda Blog

2026-07-09

Redpanda 发布文章定义“Agentic Data Plane”（代理数据平面），将其描述为连接 AI Agent 与其操作对象的治理和运行时层。文章指出，现有工具无法完全替代这一层，企业级数据平面需要具备连接 Agent、治理数据交互及运行时管理的能力。

📊 数据平台影响：随着 AI Agent 的普及，数据平台正从“为人服务”转向“为 Agent 服务”。这一概念明确了数据平台在 AI 时代的新定位——不仅是数据存储，更是 Agent 行动的治理边界，这将推动流处理平台和实时数据架构的演进。

StarTree 工程实践：构建基于 Apache Iceberg 的 Log Lakehouse

📌 StarTree Blog

2026-07-08

StarTree 发布技术文章，探讨如何构建 Log Lakehouse。文章指出日志数据价值高但存储成本昂贵，通过 Apache Iceberg 改变存储经济学，结合 StarTree 优化查询经济学，实现了日志数据的高效保留与分析。

📊 数据平台影响：日志数据是数据平台的高频场景。将日志存储迁移至基于 Iceberg 的 Lakehouse 架构，标志着数据湖仓技术在非结构化/半结构化日志领域的进一步渗透，为企业降低日志存储成本提供了新的技术路径。
