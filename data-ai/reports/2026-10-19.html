Trace security threats in multi-agent pipelines with Amazon OpenSearch Service

📌 AWS Big Data Blog

2026-10-19

AWS 发布技术博客，演示在由多个 AI Agent 组成的管道中追踪两类难以察觉的安全威胁：提示注入传播和跨租户数据外泄。方案将 Amazon OpenSearch Service 作为安全可观测层，结合 Amazon Bedrock，对每个 agent 调用记录嵌入向量、来源链路和 PII 检测结果，从而重建攻击路径，识别异常跳转、敏感数据流动和越权访问。该实践把传统日志审计扩展到 Agent 语义层，为多智能体系统提供可追溯、可检测、可响应的基础设施。

📊 数据平台影响：OpenSearch 从搜索与日志分析延伸到 Agent 安全审计，数据平台需要新增语义事件、血缘、嵌入向量和 PII 检测等数据模型，以支持 AI 安全运营。

Postgres wait events, now in Query Insights

📌 ClickHouse Blog

2026-10-19

ClickHouse 发布 Query Insights for ClickHouse Managed Postgres 的新能力，可显示活跃会话正在等待什么。更新包括等待事件分解、阻塞会话和锁等待图表，并将相同指标暴露给 Prometheus。该功能帮助数据库管理员和平台团队从传统查询耗时指标进一步下钻到 Postgres 内部等待原因，更快定位锁竞争、资源瓶颈和异常会话，提高托管数据库运维效率。

📊 数据平台影响：托管 Postgres 可观测性从查询指标深入到等待事件和锁分析，有利于将数据库性能数据接入统一监控体系，提升数据平台 SLO 诊断和故障定位能力。
