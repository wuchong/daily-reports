Amazon OpenSearch Service 推出下一代 Serverless 时序集合

📌 AWS Big Data Blog

2026-10-27

AWS 宣布 Amazon OpenSearch Service Serverless 支持下一代时序集合。用户可通过数据分层、时间字段选择和数据保留控制，定义成本、性能、安全和访问边界。该功能面向原始事件数据的接入、查询和洞察生成，适用于日志分析、指标监控、IoT 事件处理等场景，进一步减少时序工作负载的容量规划和集群运维负担。

📊 数据平台影响：时序数据平台正加速 Serverless 化，AWS 可通过托管分层和保留策略吸引日志、指标和事件数据工作负载，对独立时序数据库和部分可观测性平台形成竞争压力。

Amazon OpenSearch Service Relevance Agent 自动化搜索相关性调优

📌 AWS Big Data Blog

2026-10-27

AWS 发布 Amazon OpenSearch Service Search Relevance Agent，目标是将低 NDCG 分数的搜索问题在数分钟内转化为更优查询。用户通过 Ask AI 聊天描述问题后，Agent 会分析 User Behavior Insights 数据，生成改进查询，并通过离线 Search Relevance Workflow 进行验证。该能力将搜索优化从人工经验驱动转向 Agent 辅助的闭环流程。

📊 数据平台影响：搜索相关性调优开始进入 Agent 自动化阶段，有助于提升企业搜索、电商搜索和 RAG 检索质量。数据平台未来竞争点将从查询引擎扩展到自动化评估与优化闭环。

ClickHouse 发布 Agentic Analytics Benchmark，并用 Jev 评估表排序与失败标注

📌 ClickHouse Blog

2026-10-27

ClickHouse 发布关于 Agentic Analytics Benchmark 的博客，介绍 Jev 如何在不到一秒内对数据仓库表进行排序并标注 Agent 失败。文章同时指出，在 20 个模型上添加检索提示后，准确率并未显著提升。这表明 Agent 在数据分析中的表现不仅取决于检索速度或元数据提示，还取决于表选择、查询生成、上下文理解和结果验证等综合能力。

📊 数据平台影响：Agentic Analytics 需要更严谨的评估体系。数据平台不能只增强元数据检索，还需改进表发现、查询生成、失败归因和结果可信度验证，才能提升 Agent 分析准确性。
