Introducing Amazon OpenSearch Memory: Persistent memory for AI agents

📌 AWS Big Data Blog

2026-11-18

Amazon OpenSearch Memory 正式 GA。该服务基于 Amazon OpenSearch Serverless，为 AI agent 提供跨会话的持久记忆能力，可将交互记录为可搜索事件，自动派生记忆并检索相关上下文，帮助开发者无需自建记忆存储与检索系统，即可为 agent 增加长期上下文。

📊 数据平台影响：数据平台需新增 agent memory 层，涵盖事件存储、检索、权限和审计；OpenSearch 有望成为 agent 长期记忆入口。

Introducing the Apache Spark optimization agent for Amazon EMR Serverless and AWS Glue ETL

📌 AWS Big Data Blog

2026-11-18

AWS 推出面向 Amazon EMR Serverless 和 AWS Glue ETL 的 Apache Spark optimization agent，并宣布 GA。该 agent 会分析已完成的 Spark 作业运行遥测，在几分钟内给出成本或性能优化建议，使工程师无需深入 Spark 内部机制即可进行作业调优。

📊 数据平台影响：Spark 作业治理进入 agent 化阶段，成本优化、性能诊断和自动调优将成为数据平台标配，推动 FinOps 与 DataOps 融合。

Introducing automatic version upgrades for AWS Glue jobs

📌 AWS Big Data Blog

2026-11-18

AWS 宣布 AWS Glue 作业自动版本升级。用户将作业版本设为 auto 后，Glue 会检查破坏性变更、请求审批、迁移至最新稳定版本并验证升级后的运行，从而减少 ETL 运行时升级的人工成本、版本碎片和安全补丁滞后。

📊 数据平台影响：ETL 生命周期管理进一步自动化，数据团队需要建立审批、测试基线和回滚机制，平台工程化要求提升。
