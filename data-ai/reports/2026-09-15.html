ClickHouse 推出 TimeSeries Engine 与 PromQL 支持，瞄准 Prometheus 替代

📌 ClickHouse Blog

2026-09-15

ClickHouse 发布新的 TimeSeries Engine，并支持在 ClickHouse Cloud 中存储 Prometheus 指标、使用 PromQL 查询。该能力允许用户将指标、日志和轨迹统一在 ClickHouse 中，而无需将现有 Prometheus 查询重写为 SQL。此举将 ClickHouse 从分析型数据库进一步扩展到可观测性与时序数据平台场景。

📊 数据平台影响：若 PromQL 兼容性和成本效率得到验证，ClickHouse 可能吸引更多可观测性工作负载，推动统一遥测数据湖仓发展，并对 Prometheus 及周边时序数据库形成替代压力。

ClickHouse 推出 Replica-aware routing public beta

📌 ClickHouse Blog

2026-09-15

ClickHouse 宣布 Replica-aware routing 公开测试。由于临时表和 named sessions 通常只存在于单个 ClickHouse replica，后续查询若被路由到其他副本会无法访问相关状态。新功能可在 HTTP 或 native protocol 上将请求固定到同一 replica，以保证会话、临时表和连续查询的一致性。

📊 数据平台影响：该能力改善有状态查询场景的可用性，减少代理或负载均衡导致的一致性陷阱，有助于 ClickHouse 承载更复杂的交互式与多步分析工作负载。

📌 AWS Big Data Blog

2026-09-15

AWS 发布技术博客，介绍如何将 Microsoft Power BI 直接连接到 Amazon SageMaker Unified Studio 中的治理数据。Part 1 聚焦 IAM Identity Center-based domains，使用 Amazon Athena ODBC driver 的新认证模式，支持 DSN-based 和 DSN-less 连接，无需第三方 ODBC-JDBC bridge。
