📡 重要信号

Amazon EMR 8.1.0 增加 multi-catalog 支持

📌 AWS Big Data Blog

2026-10-06

Amazon EMR 8.1.0 通过 RedirectingSessionCatalog 支持在单一 catalog 入口中查询 Iceberg、Delta Lake、Hudi 和 Hive 表，并可跨 AWS 账户联合查询，无需复制数据。该能力面向 EMR Serverless 等场景，降低多账户、多表格式环境下的数据访问复杂度。

📊 数据平台影响：EMR 强化开放表格式互操作和跨账户治理，可能提升 AWS 湖仓作为多格式统一查询层的吸引力，并加剧与 Databricks、Snowflake 在开放湖仓上的竞争。

AWS 将 OpenSearch 与 Bedrock AgentCore 用于 ETL 可观测性

📌 AWS Big Data Blog

2026-10-06

AWS 展示将 MWAA 编排的 ETL 管道日志集中写入 Amazon OpenSearch Service，并借助 Amazon Bedrock AgentCore 上的 MCP server 以自然语言查询日志。该方案旨在减少跨 CloudWatch log groups 排障成本，将可观测性与 AI 代理能力结合。

📊 数据平台影响：将 ETL 可观测性接入 OpenSearch 与 Bedrock，有助于 AWS 形成 DataOps/AIOps 闭环，提升数据管道故障定位效率，也可能带动 OpenSearch 在运维分析场景的使用。

AWS Glue 6.0 结合 DuckDB 与 Amazon S3 Tables 提供低成本 ETL

📌 AWS Big Data Blog

2026-10-06

AWS 介绍在 AWS Glue 6.0 中使用 DuckDB 运行以 SQL 为中心的单 worker ETL，从 Amazon S3 读取 Parquet，并将 Apache Iceberg 表写入 Amazon S3 Tables。文章提供可运行示例，并与等效 Apache Spark 作业比较成本和运行时间。

📊 数据平台影响：为中小规模湖仓 ETL 提供更低成本、更轻量的替代路径，进一步推动 DuckDB、Iceberg 和 S3 Tables 在 AWS 数据平台中的组合采用。
