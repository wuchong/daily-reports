AWS Lake Formation 支持直接访问 S3 数据文件

📌 AWS Big Data Blog

2026-06-12

AWS 宣布 EMR release label 7.13 及后续版本支持通过 Lake Formation 权限直接访问 S3 数据文件。该功能通过凭证分发机制，允许 Apache Spark 作业等应用在无需复杂 IAM 策略配置的情况下，安全地读写 Lake Formation 管理的 S3 位置。

📊 数据平台影响：此举统一了数据湖的权限模型，降低了数据访问门槛。企业现在可以更细粒度地控制数据访问，无需在 IAM 和 Lake Formation 之间进行复杂的映射，显著提升了数据治理的效率与安全性。

StarTree 发布 Delta Tables：Delta Lake 的亚秒级分析方案

📌 StarTree Blog

2026-06-12

StarTree 推出 StarTree Delta Tables，为 Delta Lake 提供丰富的索引层，旨在解决 Lakehouse 架构下 SLA 驱动型工作负载的性能瓶颈。该方案允许用户在数据原址运行亚秒级分析查询，无需传统的数据变通方案。

📊 数据平台影响：填补了开源 Lakehouse 在实时 OLAP 场景下的性能空白。通过将 Apache Pinot 的实时索引能力引入 Delta Lake，StarTree 加速了“湖仓一体”在实时仪表盘等高并发场景下的落地。
