📌 AWS Big Data Blog

AWS 发布技术指南，展示如何利用 AWS DevOps Agent 配合 Apache Spark Troubleshooting Agent 诊断多层 Medallion Architecture 管道故障。关键在于将 Spark Troubleshooting Agent 集成为 MCP server，使 DevOps Agent 能够通过标准化接口调用诊断能力，将原本耗时的多层排查缩短至数分钟内完成。
