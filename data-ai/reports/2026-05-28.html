Amazon OpenSearch Serverless 新一代架构发布：专为 Agent 构建而生

📌 AWS Big Data Blog

2026-05-28

AWS 宣布对 Amazon OpenSearch Serverless 进行底层架构重构。新架构专为 AI Agent 场景优化，支持 Scale-to-zero（缩容至零），自动扩容速度提升高达 20 倍，且相比峰值负载配置成本降低 60%。这标志着 OpenSearch 从传统搜索引擎向 AI 时代向量检索与 Agent 记忆存储核心组件的转型。

📊 数据平台影响：此举直接冲击专用向量数据库市场。OpenSearch 作为成熟的开源检索引擎，通过 Serverless 形态降低 Agent 开发门槛，将推动“向量+全文”混合检索成为数据平台标配，迫使 Snowflake/Databricks 等竞品加速强化搜索能力。

ClickHouse Cloud 引入多阶段分布式查询执行

📌 ClickHouse Blog

2026-05-28

ClickHouse Cloud 发布多阶段分布式查询执行功能，允许单个查询在多个节点间分阶段执行。这一架构升级旨在解决大规模 Join 和高基数聚合的性能瓶颈，无需用户手动优化即可处理更复杂的分析负载。

📊 数据平台影响：解决了 ClickHouse 在复杂 ETL 和宽表关联场景下的短板，使其在实时数仓竞争中更具优势，缩小了与传统 MPP 数据库在复杂查询处理能力上的差距。

ClickHouse Open House 2026 Day 1：实时数据生态全景发布

📌 ClickHouse Blog | ClickHouse Blog (JP)

2026-05-28

ClickHouse 年度大会 Day 1 发布了一系列更新，包括 Postgres 集成、ClickPipes 数据摄入、ClickHouse Agents 以及 Langfuse V4 集成等。大会核心主题是“无锁定的实时数据”，旨在打通从数据摄入、存储到 AI 应用构建的全链路。
