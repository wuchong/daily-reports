Amazon MSK Express brokers 降低 Kafka 数据入湖成本

📌 AWS Big Data Blog

2026-11-16

AWS 表示 Amazon MSK Express brokers 现已可将 Apache Kafka topic 数据直接投递至 Amazon S3，最高降低 60% 成本，并无需自行运行 Kafka Connect。用户可在 topic 上创建 channel，仅按实际投递数据量付费。文章重点讨论当前 Kafka 数据入湖在运维复杂性和成本上的挑战，以及 Express brokers 的简化路径。

📊 数据平台影响：该能力将 Kafka 到 S3 的管道进一步托管化，可能降低数据入湖门槛，强化 S3/Iceberg 作为实时数据湖底座的地位，并对自建 Kafka Connect 及第三方集成工具形成替代压力。

AWS Glue 接入 Anthropic，AI 用量成本进入数据平台

📌 AWS Big Data Blog

2026-11-16

AWS 推出新的 AWS Glue connector for Anthropic，可读取 Claude 使用量、成本和 API key 等数据，无需自定义代码。文章展示将数据写入 Amazon S3 Tables 中的 Apache Iceberg 表，再通过 Amazon Athena 查询，并用 AWS QuickSight 可视化 AI 支出、访问和治理情况。

📊 数据平台影响：LLM 调用明细开始被纳入数据仓库/湖仓治理体系，数据平台将承担 AI FinOps、权限审计和成本归因职责，可能推动 AI usage observability 成为标配。

Amazon Managed Flink 增强型快照 GA

📌 AWS Big Data Blog

2026-11-16

Amazon Managed Service for Apache Flink 的增强型快照正式 GA。增强型快照作为拥有独立 ARN 的 AWS 资源，与创建它的应用解耦，可用于启动新的 Flink 应用、导出到 Amazon S3，并支持导入 savepoints，以便蓝绿部署、恢复和迁移等场景。

📊 数据平台影响：流处理状态管理从应用附属资源升级为可独立治理的云资源，有助于 Flink 的灾备、升级、测试和多环境复制，提升实时数据管道的平台化运维能力。
