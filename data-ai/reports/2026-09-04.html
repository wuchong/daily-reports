AWS 提出面向 AI Agent 的联邦数据访问参考模式

📌 AWS Big Data Blog

2026-09-04

AWS Big Data Blog 发布文章，介绍 AI Agent 如何通过 Model Context Protocol (MCP) servers 与 Amazon Bedrock AgentCore 实现联邦数据访问。文章提出 catalog-first、direct source 和 hybrid access 三种参考模式，使 AI Agent 可直接访问企业数据所在位置，减少将所有问题路由给数据工程师或集中式数据管道的依赖。

📊 数据平台影响：该模式将数据访问从集中式 ETL 转向元数据驱动、可治理的联邦访问，推动数据目录、权限、语义层和 API 化数据产品成为 AI Agent 的核心基础设施。

💻 产品与技术

ClickHouse 26.8 推出 Pipelined SQL 语法

📌 ClickHouse Blog

2026-09-04

ClickHouse 发布 26.8 版本中的 Pipelined SQL 功能，允许用户以可读的转换序列构建多阶段查询。该语法将复杂 SQL 拆解为连续处理步骤，降低嵌套子查询和 CTE 的编写复杂度，提升分析查询的可维护性，尤其适合数据工程、指标加工和交互式分析场景。

📊 数据平台影响：Pipelined SQL 强化了 ClickHouse 作为实时分析引擎的易用性，有助于扩展其在数据平台查询层、指标层和自助分析场景中的应用。
