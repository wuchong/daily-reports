Amazon SageMaker 用 Iceberg materialized views 构建 medallion architecture

📌 AWS Big Data Blog

2026-09-02

AWS 展示在 Amazon SageMaker 中使用 Apache Iceberg materialized views 构建 Bronze、Silver、Gold 三层 medallion architecture。该方式以三条 SQL 声明式定义各层数据加工，将转换、编排和增量处理折叠到每层定义中，减少传统 ETL 作业和编排器依赖。这为湖仓数据工程提供更简洁的管道抽象。

📊 数据平台影响：声明式 materialized views 可能改变数据管道构建方式，推动数据平台从作业编排转向以表和视图为中心的工程模式，并提升湖仓开发效率。

用 Apache Iceberg 和 Apache Flink 构建动态 streaming data lake

📌 AWS Big Data Blog

2026-09-02

AWS 演示在 Amazon Managed Service for Apache Flink 上构建动态流式数据湖，利用 Apache Iceberg Dynamic Iceberg Sink 实现按记录路由到不同表，并自动适应新事件类型和 schema 变化。管道无需停机即可处理结构变化，适合事件数据、日志和 IoT 等高变化场景。

📊 数据平台影响：流式湖仓可获得更强 schema evolution 和路由能力，降低实时管道因上游结构变化导致的运维中断，有助于减少停机和重跑。
