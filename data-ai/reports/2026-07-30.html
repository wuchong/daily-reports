AWS MSK 实现向 Apache Iceberg 流式表的原生交付

📌 AWS Big Data Blog

2026-07-30

AWS 宣布 Amazon MSK Express brokers 现已支持将 Kafka 流式数据直接交付到 Apache Iceberg 流式表中。该功能完全托管，无需管理连接器、Flink 作业或编写自定义消费者代码，即可将数据持续物化为 Amazon S3 Tables 上可查询的 Iceberg 表。

📊 数据平台影响：这是流式数据入湖的重大利好。它消除了维护 Kafka Connect 或 Flink 集群的运维负担，直接打通了流式数据到 Iceberg 的'最后一公里'，显著降低了构建实时数据湖的复杂度和成本，将进一步加速 Iceberg 在云原生架构中的统治地位。

优化 EMR Spark 作业中的 AWS KMS 解密 API 成本

📌 AWS Big Data Blog

2026-07-30

文章详细介绍了在 Amazon EMR 和 Apache Spark 处理加密 S3 数据时，如何应对随对象数量增长而激增的 KMS 解密 API 成本。提出了三种优化技术：优化文件格式（包括采用 Apache Iceberg）、数据聚合以及调整处理逻辑，以在保障加密安全的前提下降低费用。
