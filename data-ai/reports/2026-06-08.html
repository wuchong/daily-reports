Amazon Redshift 引入增量快照计费模式

📌 AWS Big Data Blog

2026-06-08

AWS 宣布自 2026 年 6 月 8 日起，针对 Amazon Redshift Serverless 和 Amazon Redshift RG（Graviton 实例）推出增量快照计费模式。新模式下，用户只需为跨活动手动快照的唯一数据块付费，消除了重复数据的冗余存储成本，此举旨在优化数据保护的成本效益。

📊 数据平台影响：此举直接降低了数据仓库容灾与备份的 TCO（总拥有成本），提升了 AWS 在云数仓价格战中的竞争力。对于管理大量快照的企业而言，存储成本有望显著下降，可能促使更多用户采用 Serverless 架构。

💻 产品与技术

ClickHouse Cloud 发布 Executable UDF 公共测试版

📌 ClickHouse Blog

2026-06-08

ClickHouse 宣布 Executable UDF 在 ClickHouse Cloud 中进入公共测试阶段。该功能允许用户使用 Python 编写自定义函数，打包为 zip 上传至集群，随后即可像内置 SQL 函数一样调用，打破了传统 SQL 在复杂逻辑处理上的限制。

📊 数据平台影响：填补了 ClickHouse 在复杂数据转换场景下的短板，使其能更好地承载原本需要 Spark 或 Python 脚本处理的 ETL 逻辑，向“湖仓一体”架构的计算能力更进一步。

AWS 助力 JMS 应用无缝迁移至 Amazon MQ for RabbitMQ

📌 AWS Big Data Blog

2026-06-08

AWS 发布技术指南，详细演示如何以最小改动将现有 JMS 应用迁移至 Amazon MQ for RabbitMQ。文章涵盖了从代理创建、配置到消息收发的全流程，并提供了从 Apache ActiveMQ 迁移的实际场景案例。

📊 数据平台影响：降低了传统消息队列迁移上云的技术门槛，有助于 AWS 吸引遗留系统客户迁移至其托管消息服务，巩固其在消息中间件托管市场的地位。
