Discover and govern Snowflake data using SageMaker Unified Studio

📌 AWS Big Data Blog

2026-09-16

AWS 介绍如何将 Snowflake 连接到 Amazon SageMaker Unified Studio，构建统一数据目录。用户可在不迁移数据的情况下联邦查询 Snowflake 表，将加工后的资产发布到 SageMaker Catalog，并使用 AWS Glue Data Quality 校验数据质量。该方案强调跨平台数据发现、治理和质量管理，同时保持数据留在 Snowflake 中。

📊 数据平台影响：AWS 以统一目录和治理能力嵌入 Snowflake 数据资产，可能增强 SageMaker 作为跨源 Data+AI 控制面的吸引力，同时加剧云厂商与独立数据平台间的互操作竞争。

ClickHouse is now available on the dbt platform

📌 ClickHouse Blog

2026-09-16

ClickHouse 宣布其 dbt v2 adapter 进入 public beta，该 adapter 由 dbt 的 Rust 引擎驱动。ClickHouse 同时以 private beta 方式接入 dbt 平台，支持开源 ClickHouse 和 ClickHouse Cloud。此举使数据团队可更便捷地在 dbt 工作流中使用 ClickHouse 进行转换和分析，降低集成门槛。

📊 数据平台影响：ClickHouse 与 dbt 生态结合可提升其在现代数据栈中的可采纳性，尤其利于分析工程团队将高性能 OLAP 纳入标准化 transformation 流程。
