📡 重要信号

Amazon Redshift 推出 Iceberg 物化视图

📌 AWS Big Data Blog

2026-10-05

Amazon Redshift 宣布支持 Iceberg 物化视图，可在 Redshift 中计算聚合，并将结果写入 Amazon S3 上的标准 Apache Iceberg 表。该结果可被 Amazon Athena、Apache Spark、Amazon SageMaker 和 AWS Glue 等引擎查询，文章重点介绍用例、增量刷新和多引擎共享模式。

📊 数据平台影响：数据平台可将高频聚合预计算一次，减少重复 ETL 和多引擎拷贝；Iceberg 作为共享开放表格式，提升 Redshift 与湖上引擎互操作性，但需管理表生命周期、权限和一致性。

Amazon Redshift MCP server 提供自动化运维诊断

📌 AWS Big Data Blog

2026-10-05

AWS 介绍开源 Amazon Redshift MCP server 中的 review_cluster 工具。该工具可通过一次自然语言请求运行完整集群诊断，评估 12 个诊断领域，并返回优先级排序的运维建议，体现 Redshift 在自动化运维和 AI Agent 集成上的进展。

📊 数据平台影响：MCP 将数据库运维能力暴露给 AI Agent，降低 DBA 诊断门槛；数据平台可探索自动化巡检、故障定位和优化建议，但需关注权限边界、审计和自动执行风险。

Executable UDFs 在 ClickHouse Cloud 正式 GA

📌 ClickHouse Blog

2026-10-05

ClickHouse Cloud 宣布 Executable UDFs 在 AWS、GCP 和 Azure 上正式 GA。该功能支持原生运行时、网络访问、可观测性，并提供 API 和 Terraform 支持，使用户能够通过自定义代码扩展 ClickHouse 的分析能力。

📊 数据平台影响：用户可用自定义代码扩展 SQL 分析，适配模型推理、复杂转换和外部服务调用；平台需加强 UDF 安全沙箱、资源隔离、依赖管理和数据出境治理。
