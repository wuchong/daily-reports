AWS Lake Formation 与 Trusted Identity Propagation 实现跨 Region 细粒度数据访问

📌 AWS Big Data Blog

2026-10-23

AWS 宣布 Trusted Identity Propagation 与 AWS IAM Identity Center 现已支持跨 Region 使用。企业可以在一个 Region 共享由 AWS Lake Formation 治理的 Amazon S3 和 Amazon Redshift 数据，并从另一个 Region 以实际企业用户身份查询数据，同时保留细粒度访问控制和按用户审计能力。

📊 数据平台影响：该能力有助于构建多 Region 数据湖和数据网格，在减少数据复制复杂度的同时保持统一身份、权限和审计。对于跨地域运营的企业，AWS 原生数据治理栈的吸引力进一步增强。

Amazon OpenSearch intelligent ingestion 从 Amazon S3 构建 RAG-ready 索引

📌 AWS Big Data Blog

2026-10-23

Amazon OpenSearch intelligent ingestion 是一项全托管、serverless 能力，可将 Amazon S3 中的文档和结构化数据转化为 RAG-ready、可搜索索引，无需自行管理摄取管道。AWS 同时介绍了 Ingestion Jobs 与 Ingestion Streams 的适用场景。

📊 数据平台影响：该能力降低了 RAG 应用中数据摄取、索引构建和向量检索的工程门槛，可能减少企业对自建 ETL、embedding pipeline 和部分第三方数据集成的依赖。

Shipsidekick 使用 ClickHouse Managed Postgres 替换 Neon，实现查询性能提升

📌 ClickHouse Blog

2026-10-23

Shipsidekick 将数据库从 Neon 迁移到 ClickHouse Managed Postgres，整个过程在一个周末内完成。迁移后，其 CPU 使用率从 100% 降至 5%-10%，查询速度约提升 10 倍，系统可靠性也得到改善。

📊 数据平台影响：该案例显示托管 Postgres 竞争正从兼容性和开发体验扩展到查询性能、资源效率与迁移便利性。数据平台选型将更重视真实负载下的成本与性能表现。
