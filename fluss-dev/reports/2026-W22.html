CVE-2026-49361: Apache Fluss Netty Frame Decoder Memory Exhaustion Vulnerability

0 条回复 · 1 位参与者

Apache Fluss 披露了一个重要的安全漏洞 CVE-2026-49361，该漏洞源于 Netty Frame Decoder 配置不当，允许未认证攻击者耗尽服务器内存导致拒绝服务。受影响版本为 0.8.0 和 0.9.0，社区建议用户升级至 0.9.1 版本以修复该漏洞。

@Jark Wu: 漏洞成因是 Netty LengthFieldBasedFrameDecoder 的最大帧长被设为 Integer.MAX_VALUE，导致 JVM 堆内存耗尽风险。

@Jark Wu: 该漏洞影响 Apache Fluss 0.8.0 和 0.9.0 版本，攻击者无需认证即可发起攻击。

@Jark Wu: 官方已发布 0.9.1 版本修复此问题，建议用户尽快升级。

结论：用户应立即升级至 Apache Fluss 0.9.1 版本以规避安全风险。
