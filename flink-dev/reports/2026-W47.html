[BUG] Wrong result on inner self-join with empty right input: HashAggregate(select=[]) + singleRowJoin preserves left groups

0 条回复 · 1 位参与者

讨论围绕 Flink SQL 批模式下，INNER JOIN ON TRUE 自连接且右侧输入被过滤为空时返回错误结果的 BUG。报告者指出优化计划中全局 HashAggregate(select=[]) 会使空输入仍产生一行，并通过 singleRowJoin 错误保留左侧分组。

@Weiwei Su: 在 Flink 1.19.1 中，右侧过滤为空的内连接应返回 0 行，但实际返回左侧分组，且提供了最小复现、执行结果和 DuckDB/Trino/Spark 的对比。

@Weiwei Su: 根因线索是优化器对右侧空输入应用无分组键的全局 HashAggregate，导致空输入产生单行，再经 singleRowJoin 造成错误结果。

初步判断问题来自全局空聚合与 singleRowJoin 的组合，下一步需要社区确认并修复相关优化规则或执行行为。
