Breaking change: Make IS JSON / IS NOT JSON return NULL for NULL input

7 条回复 · 5 位参与者

讨论主要关于修复 Flink 中 IS JSON / IS NOT JSON 函数在 NULL 输入下错误返回 FALSE 的问题，提议改为符合 SQL 标准的 NULL 行为。社区一致认为应遵循 SQL 标准并与其他主流引擎保持一致，同意接受此破坏性变更以修复该缺陷。最终该修复已合并至主分支，将随 Flink 2.4.0 版本发布。

@Fabian Hueske: 提议修改 IS JSON / IS NOT JSON 的行为以符合 SQL 标准（输入 NULL 时返回 NULL），虽然这是破坏性变更，但能消除 Calcite 升级带来的副作用并保持一致性。

@Timo Walther: 支持该变更，认为 NULL 输入导致 NULL 输出是 SQL 的通用逻辑，且该函数使用频率不高，应视为 Bug 尽快修复。

@dylanhz: 赞同对齐标准，并指出 IS_DECIMAL、IS_DIGIT 等函数也存在类似问题，建议单独开票处理以保持一致性。

社区达成共识，Fabian Hueske 已提交并合并了修复代码，该变更将在 Flink 2.4.0 版本中生效；同时 dylanhz 已为其他相关函数创建了新的 Jira 工单 FLINK-40141。

@Xingcan Cui: 指出使用全局 Hint 存在向后兼容风险，若未来支持新算子，旧查询的行为可能会被静默改变，建议引入 'target' 参数明确作用对象。

Weiqing Yang 已将反馈整合进 FLIP 文档，若无其他异议，计划于下周初发起投票（VOTE）。
