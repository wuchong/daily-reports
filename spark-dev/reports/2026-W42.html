SPIP: ADBC Data Source

0 条回复 · 1 位参与者

Tornike Gurgenidze 发起 SPIP 讨论，提议在 Spark 中新增内置 ADBC 数据源，作为现有 JDBC 数据源的补充。该提案利用 ADBC 返回 Arrow 列式批数据以减少行式转换和拷贝，原型测试显示读取列式数据库可比 JDBC 快 3-10 倍。

@Tornike Gurgenidze: 提议新增可选的 adbc format，不修改现有 JDBC 数据源和公共 API，ADBC 主要用于提升列式数据库读取性能。

@Tornike Gurgenidze: ADBC 数据源计划支持列裁剪、过滤、limit、Top-N 和基础聚合下推，并结合 JDBC 风格 range partitioning 与 ADBC driver partitioning。

@Tornike Gurgenidze: 写入方面支持通过 ADBC bulk ingest 追加数据，在驱动支持时按任务事务提交，并提供与 JDBC writer 类似的 at-least-once 保证。

目前该提案仍处于社区讨论和原型验证阶段，尚未形成最终结论；下一步预计围绕 SPIP 文档、JIRA SPARK-60255 及原型实现继续推进评审。
